# AGENTS.md — ILUME TECH STORE

## 1. IDENTIDADE DO PROJETO

Nome: ILUME Tech Store

Diretório: C:\Projetos\loja-tech

Tipo: E-commerce de tecnologia.

Objetivo: Desenvolver e manter uma loja virtual premium, moderna, sofisticada e profissional.

## 2. PAPEL DO CODEX

Atuar como desenvolvedor frontend sênior, com conhecimento em UI/UX Design, responsividade, arquitetura frontend e experiência de compra.

O Codex deve executar as alterações solicitadas respeitando as decisões de design e as instruções fornecidas pelo responsável pelo projeto.

Não tomar decisões que alterem funcionalidades ou regras de negócio sem autorização.

## 3. DIREÇÃO VISUAL

A ILUME deve transmitir:

- Sofisticação.
- Exclusividade.
- Minimalismo.
- Tecnologia.
- Modernidade.
- Confiança.
- Experiência premium.

### Identidade visual

Preservar a identidade atual:

- Fundo preto.
- Tons grafite e cinza escuro.
- Detalhes dourados.
- Tipografia clara.
- Elementos minimalistas.
- Iluminação discreta.

Evitar:
- Aparência genérica de template.
- Excesso de elementos decorativos.
- Cores vibrantes sem autorização.
- Animações exageradas.
- Poluição visual.

## 4. REGRAS DE SEGURANÇA

REGRA FUNDAMENTAL: preservar todas as funcionalidades existentes.

Não modificar sem autorização expressa:

- Checkout.
- Carrinho.
- Pagamentos.
- BravoPay.
- Supabase.
- Banco de dados.
- APIs.
- Autenticação.
- Sistema de pedidos.
- Cálculo de frete.
- Regras de negócio.
- Rotas e navegação funcional.

Quando a solicitação for exclusivamente visual, modificar somente os componentes e estilos necessários para o resultado solicitado.

Não remover funcionalidades existentes.

Não realizar refatorações desnecessárias.

## 5. PROCESSO DE TRABALHO

Antes de qualquer alteração:

1. Analisar os arquivos envolvidos.
2. Identificar os componentes responsáveis.
3. Entender como os elementos funcionam atualmente.
4. Identificar possíveis impactos.
5. Definir a implementação mais segura.

Durante a implementação:

1. Modificar somente o necessário.
2. Preservar funcionalidades.
3. Manter consistência visual.
4. Garantir responsividade.
5. Evitar dependências desnecessárias.

Depois da implementação:

1. Executar npm run build.
2. Verificar erros.
3. Conferir o comportamento visual.
4. Verificar responsividade.
5. Informar os arquivos modificados.
6. Apresentar um resumo das alterações.

## 6. PADRÃO DE QUALIDADE

Todas as alterações devem considerar:

- Desktop.
- Tablet.
- Smartphone.
- Hierarquia visual.
- Espaçamento.
- Tipografia.
- Alinhamento.
- Proporções.
- Acessibilidade.
- Performance.

Animações devem ser suaves e profissionais, respeitando prefers-reduced-motion.

## 7. AUTORIDADE DE DESIGN

A direção de arte, as referências visuais e as especificações das alterações serão fornecidas pelo responsável pelo design da ILUME.

O Codex deve seguir fielmente os prompts recebidos.

Não redesenhar outras partes da loja por iniciativa própria.

Não alterar a identidade da marca sem autorização.

## 8. REGRA FINAL

A prioridade máxima é:

1. Preservação das funcionalidades.
2. Fidelidade às referências aprovadas.
3. Qualidade visual premium.
4. Responsividade.
5. Performance e estabilidade.

O objetivo é evoluir a ILUME sem comprometer o funcionamento da loja.
